Questions & Answers

Anticipated Questions & Technical Defenses

Key Technical Inquiries & Authoritative Answers

❓ Why In-Context Grounding over RAG?
For contracts under 100 pages, in-context grounding avoids chunking errors and retrieval misses, guaranteeing 100% context recall and cross-page synthesis.
❓ How are quotes verified?
Our LLM Judge performs string matching against the ingested text. If a quote is paraphrased or missing, it is flagged as ungrounded.
❓ How do you prevent prompt injection?
Document text is wrapped in strict delimiter boundaries. The system prompt instructs the model to treat document content purely as passive data.
❓ How does cost tracking work?
FastAPI captures token usage directly from API responses, multiplying prompt and completion counts by published rates in real time.
